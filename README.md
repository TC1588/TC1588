# A marketer who ships the measurement

Growth and product marketing lead at Musicow, a music-royalty investing marketplace. Paid acquisition across six channels, go-to-market, and the analytics product the company reads its catalog by. Before that, product marketing for the Media and Entertainment vertical at TikTok, and programmatic at Sony Pictures.

Los Angeles, CA

Most of what I build is internal and runs on licensed data, so the code stays private. The method does not. These are the parts I would hand to someone starting the same work.

- **[metrics-framework](https://github.com/TC1588/metrics-framework)**. Designing a North Star that survives an executive asking where the number came from. Input metrics as levers, health guardrails tied to the failure each one guards against, and modeled numbers kept visibly separate from measured ones.
- **[never-fabricate](https://github.com/TC1588/never-fabricate)**. What a data pipeline should do when a source fails. A four-step degrade ladder, written after a lapsed vendor account published sample data as though it were live, at roughly double the true figure.
- **[refutation-review](https://github.com/TC1588/refutation-review)**. A 35-agent code review where every finding had to survive a second agent trying to disprove it. 407 tool calls, 28 confirmed bugs, about fifteen minutes.
